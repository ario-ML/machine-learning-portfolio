# Machine Learning Portfolio

A collection of Python and Jupyter projects covering regression, classification, exploratory data analysis, and recommender systems.

## Featured project

[MovieLens 100K recommendation system](./Recommendation-System.ipynb/Recommendation-System.ipynb) explores item similarity and predicts ratings using linear regression with one-hot encoded user and movie IDs. On the saved test split, the model achieved **MAE 0.7425** and **RMSE 0.9431**, compared with **MAE 0.9420** for a mean-rating baseline (about 21.2% lower MAE).

## Run the notebooks

Install Jupyter, NumPy, pandas, Matplotlib, and scikit-learn with `python -m pip install notebook numpy pandas matplotlib scikit-learn`. Open the notebook from its project folder in Jupyter. Check its data-loading cells for the required dataset files. The MovieLens data is included alongside its notebook.
